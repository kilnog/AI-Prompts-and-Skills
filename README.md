# AI Prompts & Skills

A public collection of AI prompts, reusable skills, and project-based workflows.

## Structure

```text
ai-prompts-skills/
├── prompts/
├── skills/
├── projects/
└── README.md
```

## Prompts

Standalone prompts designed to be copied into a chat and used directly.

Examples:

- One-off prompts
- Reusable prompt templates
- Role-specific prompts
- Task-specific prompts

## Skills

Reusable instructions that give an AI a repeatable capability, process, or way of working.

Examples:

- Agent skills
- Structured instructions
- Repeatable workflows
- Tool-specific behaviours
- Reusable operating procedures

## Projects

Outcome-focused prompt packs and workflows that combine multiple prompts, skills, files, or steps.

Examples:

- Multi-step workflows
- Project templates
- Prompt packs
- End-to-end AI processes
- Outcome-focused examples

## Usage

Browse the relevant folder, copy what you need, and adapt it to your preferred AI tool or workflow.

Prompts and skills may require minor changes depending on the model, platform, or tools available.
